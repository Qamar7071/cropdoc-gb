# Translations

- `en.json`: English (source of truth for keys).
- `ur.json`: Urdu. **Machine-written: needs review by a native Urdu speaker.** Edit the values
  freely (keep the keys). Missing Urdu keys fall back to English automatically.
- Crop and district names have `crop.*` / `districtName.*` keys (Urdu only; English uses the raw name).
- Disease names and library text come from the backend in English (`backend/app/data/diseases.json`).

Selecting Urdu switches the page to right-to-left (`<html dir="rtl" lang="ur">`).
